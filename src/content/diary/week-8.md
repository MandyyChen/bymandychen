### reading: systems esthetics (jack burnham, 1968)

burnham argues that culture is shifting from object-oriented to systems-oriented. what matters is less the thing itself and more the relationships and processes between people, things, and environments. for art, that means the work can be a system rather than a static object.

it's wild that this was written in 1968, because it reads like a description of this class. a circuit is a system before it's an object: sense, process, act.

it also reframes my own work so far. the coming home house is cardboard and an led, but the actual piece is the sequence: step, ring, knock, light. the object is just where the system lives.
